# Mídia do Instagram da AWR Baterias

Repositório usado pelo agente "Postagem no Instagram" (@awrbaterias).

- `fotos/` — banco de fotos reais, já em 1080x1350 e com placas borradas. `fotos/fotos.json` descreve cada uma.
- `modelos/` — modelos de arte (`texto.html`, `foto.html`, `base.css`) e `render.py`.
- `instagram/` — artes publicadas e `log.json`, o histórico de posts.
